# Mebalife — Kurumsal Web Sitesi

Mebalife Yapı Mimarlık Mühendislik İnşaat San. Tic. Ltd. Şti. kurumsal web sitesi (tasarım taslağı).

## Siteyi görüntüleme

`index.html` dosyasına çift tıklayın — kurulum gerekmez, tüm stil/script/logo dosyanın içine gömülüdür.

Yerel sunucu ile açmak isterseniz:

```
powershell -ExecutionPolicy Bypass -File .\dev.ps1
```

Ardından http://localhost:5173 adresini açın.

## Bölümler

- İşlerimiz — künyeli iş arşivi (Tamamlandı / Devam Ediyor / Planlanıyor filtreli)
- Biz Kimiz — ekip, kapasite ve doğrulanabilir belgeler
- Nasıl Çalışıyoruz — 6 adımlı süreç haritası
- Şantiye Günlüğü — tarihli fotoğraf akışı
- Dürüst Cevaplar — süreç soruları
- İletişim — sunum dosyası talebi

## Durum

Tasarım taslağıdır. Köşeli parantezle işaretli alanlar (`[eklenecek]`) gerçek veri geldiğinde doldurulacaktır:
proje künyeleri, YAMBİS belge numarası, sigorta poliçeleri, ekip bilgileri ve iletişim bilgileri.
